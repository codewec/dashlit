# Резервные копии и обновления

DashLit использует SQLite и хранит загруженные файлы на диске. Полная резервная копия включает базу и пользовательские иконки.

## Что сохранять

```text
bookmarks.db   обязательно
icons/         обязательно при использовании загруженных иконок
icon-cache/    необязательно, кеш можно восстановить
```

До проверки legacy-миграции также сохраняйте `dashboard.json`.

## Безопасное копирование

Самый простой согласованный backup создаётся при остановленном контейнере:

```bash
docker compose stop dashlit
# Скопируйте или сделайте snapshot постоянного тома.
docker compose start dashlit
```

Для копирования без простоя используйте online backup SQLite или snapshot хранилища с гарантией согласованности. Простое копирование активного SQLite-файла может дать повреждённую копию.

## Обновление

1. Прочитайте [историю изменений](/ru/changelog).
2. Сделайте резервную копию.
3. Загрузите выбранный образ.
4. Пересоздайте контейнер.
5. Проверьте дашборды, вход и загруженные иконки.

```bash
docker compose pull
docker compose up -d
docker compose logs --tail=100 dashlit
```

Для предсказуемого отката фиксируйте версии образа. При откате через границу миграции базы восстанавливайте соответствующую резервную копию, а не открывайте изменённую базу старой версией приложения.

## Восстановление

Остановите DashLit перед заменой данных. Восстановите `bookmarks.db` и `icons/` вместе, проверьте владельца и права, затем запустите контейнер и изучите логи.
