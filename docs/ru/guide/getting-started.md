# Знакомство

DashLit — самостоятельно размещаемая стартовая страница для закладок и сервисов. Она объединяет визуальные дашборды, многопользовательский доступ, OIDC-аутентификацию, базовую проверку доступности адресов и переносимый экспорт.

## Возможности

В одной установке может быть несколько дашбордов. Каждый дашборд состоит из упорядоченных групп, а группы — из ссылок. Группы и ссылки можно перемещать перетаскиванием и отображать в подходящей раскладке.

- **Публичные дашборды** доступны без авторизации.
- **Дашборды для пользователей** доступны всем вошедшим пользователям.
- **Приватные дашборды** доступны только владельцу и администраторам.
- **Главный системный дашборд** используется как общая стартовая страница.
- Каждый пользователь может выбрать собственный **дашборд по умолчанию**.

Поддерживаются раскладки строками, колонками и masonry, обычная и увеличенная ширина, чистый режим, отдельные иконки для светлой и тёмной темы и проверка доступности ссылок.

## Пользователи и администрирование

Первая учётная запись в пустой базе данных становится администратором. Следующие учётные записи создаются как обычные пользователи.

Пароль и OIDC можно использовать одновременно. По умолчанию OIDC-профиль с совпадающим именем связывается с существующей парольной учётной записью, сохраняя оба способа входа. Автоматическое связывание можно отключить.

## Хранение данных

Стандартный контейнер хранит постоянные данные в `/data`:

```text
/data/
├── bookmarks.db       # база данных SQLite
├── icons/             # загруженные иконки
└── icon-cache/        # восстанавливаемый кеш внешних иконок
```

Размещайте каталог на постоянном хранилище и включайте базу данных и загруженные иконки в резервные копии.
