# Дашборды и доступ

## Создание первого дашборда

Войдите, создайте дашборд и выберите уникальный slug. Он станет частью адреса, например `/infrastructure`. Добавьте группы для связанных сервисов, затем создайте ссылки внутри групп.

В режиме редактирования группы можно менять местами, а ссылки — перемещать внутри группы или между группами. Новая раскладка сохраняется на сервере.

## Уровни доступа

| Видимость | Гость | Пользователь | Владелец или администратор |
| --- | ---: | ---: | ---: |
| Публичный | ✓ | ✓ | ✓ |
| Для авторизованных | — | ✓ | ✓ |
| Приватный | — | — | ✓ |

Администратор может назначить неприватный дашборд главным системным. Он показывается гостям и пользователям без персонального дашборда по умолчанию.

Пользователь может назначить один из собственных дашбордов персональным дашбордом по умолчанию.

## Раскладка и оформление

- **Строки** размещают группы горизонтальными секциями.
- **Колонки** организуют группы по столбцам.
- **Masonry** компактно раскладывает группы с учётом их высоты.
- **Широкий режим** использует больше ширины окна.
- **Чистый режим** убирает лишнюю навигацию.

## Поиск иконок и варианты для тем

Picker независимо выполняет поиск в двух источниках:

- **selfh.st/icons** специализируется на приложениях и сервисах для самостоятельно размещаемой инфраструктуры.
- **Iconify** предоставляет большую коллекцию универсальных наборов иконок.

Результаты Iconify отображаются сразу после ответа. Более медленный поиск selfh.st продолжается независимо и добавляет свои результаты, не блокируя и не заменяя выдачу Iconify.

Для selfh.st DashLit предпочитает SVG и использует PNG, только если SVG отсутствует. При выборе selfh.st-иконки в поле Default пустое поле Dark автоматически заполняется соответствующим вариантом для тёмной темы. Уже выбранная вручную Dark-иконка не перезаписывается.

По соглашению selfh.st тёмное изображение используется на светлом фоне, а светлое — на тёмном. Если отдельного варианта нет, стандартная иконка используется в обоих полях. Загруженные файлы selfh.st отдаются через API DashLit и кешируются на диске.

Многие монохромные иконки Iconify изначально чёрные. В тёмных темах DashLit отображает их светлым цветом, чтобы они оставались видимыми. Изменение цвета применяется только к Iconify — брендовые цвета и theme-варианты selfh.st сохраняются.

В picker’е Default-иконка показывается на светлом фоне, а Dark-иконка — на тёмном. Любое поле можно изменить вручную, загрузить собственный файл или указать URL изображения.

## Проверка доступности

Включите ping у ссылки, чтобы показывать доступность адреса. Режим «только при недоступности» скрывает индикатор у работающих сервисов.

Это вспомогательный сигнал от сервера DashLit, а не замена полноценному мониторингу и оповещениям.

## Импорт, экспорт и клонирование

Экспорт создаёт переносимый JSON с настройками дашборда, группами и ссылками. Импорт создаёт новый дашборд текущего пользователя и автоматически разрешает конфликты slug.

Также можно клонировать целые дашборды, отдельные группы и ссылки.
