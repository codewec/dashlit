# Дашборды и доступ

## Создание первого дашборда

Войдите, создайте дашборд и выберите уникальный slug. Он станет частью адреса, например `/infrastructure`. Добавьте группы для связанных сервисов, затем создайте ссылки внутри групп.

В режиме редактирования группы можно менять местами, а ссылки — перемещать внутри группы или между группами. Новая раскладка сохраняется на сервере.

## Уровни доступа

| Видимость          | Гость | Пользователь | Владелец или администратор |
| ------------------ | ----: | -----------: | -------------------------: |
| Публичный          |     ✓ |            ✓ |                          ✓ |
| Для авторизованных |     — |            ✓ |                          ✓ |
| Приватный          |     — |            — |                          ✓ |

Администратор может назначить неприватный дашборд главным системным. Он показывается гостям и пользователям без персонального дашборда по умолчанию.

Пользователь может назначить один из собственных дашбордов персональным дашбордом по умолчанию.

## Раскладка и оформление

- **Строки** размещают группы горизонтальными секциями.
- **Колонки** организуют группы по столбцам.
- **Masonry** компактно раскладывает группы с учётом их высоты.
- **Широкий режим** использует больше ширины окна.
- **Чистый режим** убирает лишнюю навигацию.

## Управление с клавиатуры

### Быстрый фильтр

Начните печатать в любом месте дашборда, чтобы отфильтровать его ссылки. В обычном режиме текст появится в поле фильтра в навигационной панели. В чистом режиме DashLit показывает всплывающее поле, пока есть запрос. Нажмите **Esc**, чтобы очистить фильтр.

### Перемещение по ссылкам

Используйте **стрелки**, чтобы выбрать ссылку по её положению на дашборде. Нажмите **Enter**, чтобы открыть выбранную ссылку. **Esc** снимает выделение; также он завершает режим редактирования, если не открыто диалоговое окно или меню.

### Хоткеи ссылок и дашбордов

При создании или редактировании ссылки либо дашборда на экране настольного размера установите фокус в поле **Hotkey** и нажмите сочетание с **Ctrl**, **Alt**, **Shift** или **Meta** и другой клавишей. Удалить сочетание можно клавишами Backspace или Delete либо кнопкой Clear.

Хоткей ссылки открывает все совпадающие ссылки на текущем дашборде. Хоткей дашборда переключает только между вашими дашбордами. Хоткеи дашбордов уникальны для каждого пользователя и не показываются и не обрабатываются для чужих дашбордов или гостей. Хоткей дашборда не может совпадать с хоткеем одной из ваших ссылок.

## Темы и собственные темы

Откройте меню тем в навигационной панели или через плавающую кнопку в чистом режиме, чтобы выбрать одну из встроенных светлых или тёмных тем. Пункт **Edit colors…** создаёт собственную тему. Если собственной темы ещё нет, редактор заполняется цветами выбранной в данный момент темы.

В редакторе можно настроить цвета страницы, поверхностей, текста, основных элементов, акцентов, ошибок и успешных состояний, выбрать светлую или тёмную цветовую схему и добавить фоновое изображение. Фон можно указать URL-адресом. Авторизованные пользователи также могут загрузить изображение непосредственно в DashLit; для гостей загрузка файлов недоступна.

После сохранения пункт **Custom** появляется в общем списке тем и переключается без повторного открытия редактора. Кнопка **Delete theme** удаляет собственную тему и возвращает системную. У авторизованного пользователя выбранная тема, палитра и ссылка на фон сохраняются в аккаунте и доступны в других браузерах. Настройки гостя хранятся только в текущем браузере.

## Поиск иконок и варианты для тем

Picker независимо выполняет поиск в двух источниках:

- **selfh.st/icons** специализируется на приложениях и сервисах для самостоятельно размещаемой инфраструктуры.
- **Iconify** предоставляет большую коллекцию универсальных наборов иконок.

Результаты Iconify отображаются сразу после ответа. Более медленный поиск selfh.st продолжается независимо и добавляет свои результаты, не блокируя и не заменяя выдачу Iconify.

Для selfh.st DashLit предпочитает SVG и использует PNG, только если SVG отсутствует. При выборе selfh.st-иконки в поле Default пустое поле Dark автоматически заполняется соответствующим вариантом для тёмной темы. Уже выбранная вручную Dark-иконка не перезаписывается.

По соглашению selfh.st тёмное изображение используется на светлом фоне, а светлое — на тёмном. Если отдельного варианта нет, стандартная иконка используется в обоих полях. Загруженные файлы selfh.st отдаются через API DashLit и кешируются на диске.

Многие монохромные иконки Iconify изначально чёрные. В тёмных темах DashLit отображает их светлым цветом, чтобы они оставались видимыми. Изменение цвета применяется только к Iconify — брендовые цвета и theme-варианты selfh.st сохраняются.

В picker’е Default-иконка показывается на светлом фоне, а Dark-иконка — на тёмном. Любое поле можно изменить вручную, загрузить собственный файл или указать URL изображения.

## Проверка доступности

Включите проверку доступности у ссылки, чтобы показывать состояние адреса. По умолчанию DashLit проверяет основной URL, но можно указать отдельный адрес проверки — например, внутренний адрес или специальный health endpoint. Включайте **Skip TLS verification** только для доверенного endpoint с самоподписанным или несовпадающим сертификатом. Режим «только при недоступности» скрывает индикатор у работающих сервисов.

Это вспомогательный сигнал от сервера DashLit, а не замена полноценному мониторингу и оповещениям.

## Импорт, экспорт и клонирование

Экспорт создаёт переносимый JSON с настройками дашборда, группами и ссылками. Импорт создаёт новый дашборд текущего пользователя и автоматически разрешает конфликты slug.

Также можно клонировать целые дашборды, отдельные группы и ссылки. В меню действий группы выберите **Copy to dashboard…**, затем укажите другой доступный для редактирования дашборд. Группа будет скопирована туда вместе со всеми ссылками и настройками.
